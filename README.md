# 💕 Valentine's Date Invitation Website

A cute and interactive Valentine's Day website to ask someone special on a date!

## 🌐 Live Demo

**[Click here to view the live website!](https://shrinikatelu.github.io/love-valentine-website/)**

## ✨ Features

- 💝 Beautiful animated Valentine's theme with floating hearts
- 🎯 Interactive "Yes/No" question with a playful twist - the NO button runs away!
- 📋 Multi-select date activity planner
- 🎬 Choose from activities: Movie, Candle Light Dinner, Temple, Game Zone & more
- 📱 Fully responsive design for mobile and desktop
- ✨ Smooth animations and transitions

## 🛠️ Technologies Used

- HTML5
- CSS3 (Animations, Flexbox, Grid)
- Vanilla JavaScript

## 📁 Project Structure

```
love-valentine-website/
├── index.html      # Main question page
├── page2.html      # Date activity selection page
├── styles.css      # All styles and animations
├── script.js       # Interactive functionality
└── README.md       # This file
```

## 💖 How It Works

1. **Page 1**: Asks "Will you go on a Valentine's date with me?"
   - Click **YES** → Goes to the activity selection page
   - Try to click **NO** → The button runs away! 😄

2. **Page 2**: Select multiple date activities to create the perfect Valentine's itinerary

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shrinikatelu/love-valentine-website.git
   ```

2. Open `index.html` in your browser, or use a local server:
   ```bash
   python3 -m http.server 8000
   ```

3. Visit `http://localhost:8000`
